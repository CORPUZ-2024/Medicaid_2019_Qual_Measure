    Year-over-year baseline by program × domain

    For every program × domain × transition, the baseline is the average direction-adjusted change across all comparable state × rate changes in that group. A state's change is Improving / Declining when it is more than ½ SD better / worse than its group's baseline, otherwise Stable. These labels are relative to the baseline: a state can be “Improving” with a small decline if most states declined more.

    Units differ within some domains (most rates are percentages, but PQI admission rates are per 100,000 beneficiary months, ED visits are per 1,000 beneficiary months and PCR-AD is a ratio). Within a domain these are averaged together, so a large SD often reflects a per-100,000 rate rather than unusual movement.

    State roll-up

    Each state's mean direction-adjusted change across all its comparable rate changes (both transitions). Rates keep their own units, so a state's average can be pulled by a rate measured per 1,000 or per 100,000 (for example ED visits or admissions).
