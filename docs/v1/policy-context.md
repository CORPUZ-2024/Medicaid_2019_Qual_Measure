# Policy & funding landscape — dated context panel

**Last reviewed: 2026-09-03.** This panel is maintained by hand and sits *outside*
the annual data-refresh cycle, because legislative status changes faster than the
Core Set data does. It is **forward-looking context, not a causal explanation** of
any 2022–2024 measure movement — the laws below postdate every year of data in
this build.

## The 2025 federal budget reconciliation law (H.R. 1)

The single most consequential current input. It restructures Medicaid financing
in ways that bear on quality-measure trajectories going forward:

- **New work-and-reporting requirements** on ACA-expansion adults from
  **January 1, 2027**. States must stand up new eligibility-verification and
  data-sharing systems — administrative capacity that competes directly with the
  staff and systems states use for Core Set reporting and quality improvement.
- **Provider-tax restrictions** and **reduced federal matching**. Independent
  estimates put the federal Medicaid spending reduction at roughly
  **$0.9–1.0 trillion over ten years**.
- Because states fund well under half of total Medicaid spending on average
  (~35% in FFY2024), a state-side reduction has an **amplified** effect on total
  program spending.
- States are **responding unevenly** — some absorbing costs into general funds
  and phasing in work requirements, others more exposed to the provider-tax and
  expansion-financing changes. This state-by-state variation is what the
  regional / state at-risk view is built to surface.

## Reporting-regime change already in effect

- The **2024 Core Set** made Child Core Set reporting, and the Adult behavioral
  health measures, **mandatory** (50 states, DC, PR, USVI, Guam). This is a
  data-comparability event inside the trend window — see the
  [Trends page](trends.html) 2.3a note.
