# `docs/` — GitHub Pages site

Static site implementing Sections 1–4 of
`project_plan/Medicaid_ViewB_GitHub_Pages_Implementation_Spec_v2.txt`.

| Page | Spec section |
|------|--------------|
| `index.html` | 1 — View B extension (Adult + Child, all measures, 2024) + composite state summary |
| `trends.html` | 2.2 / 2.3 — 2022–24 baseline, classification, comparability gate |
| `regional.html` | 2.4 — HHS-region stratification |
| `risk.html` | 3.2 — at-risk / positioned-for-success scoring |
| `policy.html` | 3.1 — dated policy & funding panel (`policy-context.md`) |
| `limitations.html` | 4 — limitations (`limitations.md`) |
| `methodology.html` | how every number is produced (`methodology.md`) |

## Data

`data/*.json` is generated by `python run.py` at the repo root (which reads
`../data/raw/*.csv` from data.medicaid.gov). Charts render client-side with
Plotly (CDN). No build step, no framework.

## Enabling Pages

Repo **Settings → Pages → Source: Deploy from a branch**, branch `master`,
folder `/docs`. `.nojekyll` is present so files are served verbatim.

## Local preview

```
python run.py                 # (re)build docs/data/*.json
cd docs && python -m http.server 8765
# open http://localhost:8765/
```
